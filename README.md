# PaperTrail 🧾
> The digital audit of a human life.

PaperTrail transforms fragmented digital moments—2 AM songs, transit tickets, late-night snacks, and saved notes—into an interactive, receipt-based life chronicle. Uncover hidden connections, narrative chapters, and the emotional archaeology of a digital soul through tactile design and fluid GSAP storytelling.

Built for **WebRush — The 6-Hour Frontend Challenge**.

## ✨ Features
- **The Story Reel (Narrative Chapters):** Interactive narrative chapters tracing human phases through connected receipts.
- **The Receipt Vault (Deep Explorer):** Search, multi-dimensional filtering, and time-of-day queries (e.g. Night Owl mode).
- **The Connection Matrix:** Discover how an unrelated 2 AM song, a train ticket, and a note link into a single moment.
- **The Life Receipt Printer:** Interactive animated thermal receipt printer simulation powered by GSAP.

## 🛠️ Stack
- React + Vite
- GSAP 3 (GreenSock Animation Platform)
- Vanilla CSS Custom Properties & Design Tokens
- Lucide React Icons
- 100% Client-side (No backend)
