# PaperTrail — AI Project Context

## Project Overview
- **Name:** PaperTrail
- **Repository:** https://github.com/Shivansh1824/PaperTrail
- **Challenge:** WebRush — 6-Hour Frontend Hackathon (FrontendArena)
- **Problem Statement:** "Your Life, In Receipts"
- **Goal:** Build an interactive, frontend-only storytelling experience that transforms fragmented digital receipts (music, transit, food, notes, late-night searches) into meaningful connected narratives.

## Architecture & Tech Stack
- **Framework:** Vite + React
- **Animations:** GSAP 3 (ScrollTrigger, timelines, stagger, tactile thermal receipt effects)
- **Design System:** Custom CSS design tokens (Paper texture / monospace receipts meets modern dark aesthetic)
- **Icons:** Lucide React
- **Data:** Curated, high-fidelity JSON derived from real Spotify streaming history (2013-2024) and Daily Household Transactions (2015-2018), enriched with digital breadcrumbs (photos, searches, messages, notes).

## Core Principles
1. **Frontend Only:** Strictly no backend. All data parsing, filtering, and animation occurs client-side with zero lag.
2. **Beyond Timelines:** Must discover relationships, emotional chapters, and patterns across multi-modal data.
3. **High Design Craft:** Tactile interactions, thermal paper receipt printing simulation, responsive across mobile and desktop.
4. **Git Safety:** Clean commits, no AI assistant naming in commit logs.
